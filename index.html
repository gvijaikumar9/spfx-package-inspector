SPFx Package Inspector

Check an SPFx package before you approve it. Drop an .sppkg file to see the API permissions it requests, the domains its code talks to, how it deploys, and anything that looks like a secret.

Your package never leaves your browser. It is unzipped and checked in this tab.

.sppkg only · up to 100 MB · nothing is uploaded

What it checks

API permission requestsEvery Graph or custom API scope the package asks for, rated by how much data it reaches.
Domains in the codeHosts found in the shipped JavaScript, split into Microsoft, third-party, and documentation links.
Deployment scopeTenant-wide availability, extensions that switch on for every site, and code loaded from outside the package.
Secrets and keysStrings shaped like client secrets, storage keys, SAS tokens, private keys and API keys. Values are masked.
ComponentsEvery web part, extension and library in the package, with its ID, version and supported hosts.
Bundle hygieneBundle size, source maps, and old build files left in the package.
